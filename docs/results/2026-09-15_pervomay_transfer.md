# Первомайская без обучения: веса финального RobotCar

Сгенерировано 2026-09-15; код — адаптер `pervomay` и команда `tgseqloc transfer`. Генератор конфигов — `experiments/generators/setup_pervomay.py`, раннер — `experiments/runners/pmtransfer_run.sh`, таблица — `docs/results/scripts/pervomay_transfer.py`.

## Конфигурация

| Параметр | Значение |
|---|---|
| Данные | Первомайская, фронтальная камера 1280×720, каждый 10-й кадр (шаг ≈ 0.5 м) |
| Запросы → база | прогулка 27-08-26 (5 024 кадра) → 28-08-26 (8 734 кадра) |
| Ground truth | `poses.csv` обеих прогулок в общей системе координат; расстояние 3D (третья ось системы не вертикальна) |
| Правильный кадр | основная метрика ≤ 25 м, дополнительная ≤ 10 м; у всех 5 024 запросов есть кадр в 25 м, у 4 883 — в 10 м |
| Графы | Mask2Former swin-large COCO panoptic (`Datasets/scene_graphs_pervomay_m2f`), та же постобработка, что на RobotCar |
| Текст | PaddleOCR v5 eslav; фильтр мусора (длина ≥ 3, не только цифры); фильтр динамики YOLO11x-seg, IoA ≥ 0.5 |
| Словарь классов | из манифеста RobotCar (`preprocess.vocabulary_manifest`); вне словаря — 0.9 % узлов-объектов (читаются как unknown) |
| Веса | RobotCar, 4 камеры, Mask2Former, PaddleOCR, 10/25, прогрев, GAT 1 слой 256/256, сид 42, фолды 0–4: `final4` (тройки с любой камеры) и `final4s` (тройки с той же камеры) |
| Нормализатор рёбер | из чекпойнта; на Первомайской ничего не подбирается |

Варианты для каждого набора весов:

| Вариант | Веса | Вход |
|---|---|---|
| слагаемое | со слагаемым | текст PaddleOCR |
| без текста | без текста | графы без текста |
| текст удалён | со слагаемым | графы без текста |
| перемешанный текст | со слагаемым | строки переставлены между кадрами (seed 20260911, как на RobotCar) |

Попадание запроса усредняется по 5 моделям; интервалы — бутстрэп по 15 участкам по 200 м пройденного пути прогулки-запроса; p — знаковый перестановочный тест по участкам.

**Проверка кода.** `tgseqloc transfer` с чекпойнтом `final4-add-f0-s42` на его собственных данных RobotCar дал R@1 46.1055 / R@5 65.4523 / R@10 70.9799 на 796 запросах — те же числа, что в `final_metrics.json` прогона, и побитно тот же `test_retrievals.json`.
