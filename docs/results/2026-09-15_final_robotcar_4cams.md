2. **Текст в этой конфигурации не добавляет качества на RobotCar**: слагаемое − без текста = −1.2 R@5 (p = 0.038) при тройках с любой камеры и −1.35 R@5 (p = 0.06), −2.2 R@1 (p = 0.001) при тройках внутри камеры. Эффект зависит от участка маршрута: на фолдах 0–1 текст даёт +1.3…+1.8 R@5, на фолдах 2–4 отнимает до −3.7; сильнее всего страдают запросы левой камеры (−3.3 R@5 при тройках с любой камеры), у которой больше всего статичного текста.
3. **Сиды сходятся**: sd R@5 по сидам 0.47 (слагаемое) и 0.56 (без текста) при sd между фолдами 7.6 — главный источник разброса участок маршрута.
4. Лучшая конфигурация по recall — **тройки внутри камеры, без текста**: 58.6 / 74.1 / 80.0 / 85.8 / 92.3 (R@1/5/10/25/100, сид 42).
