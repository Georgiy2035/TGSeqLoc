# Эксперименты

- `generators/` — скрипты, которые порождают конфиги экспериментов в `configs/` из базовых.
- `runners/` — очереди прогонов: порядок, ожидание карты, побитные проверки воспроизводимости.
- `data/robotcar_folds.json` — разметка блочной кросс-валидации RobotCar (28 участков по 200 м, 5 фолдов,
  буферы 25 м, стратификация по плотности текста Qwen); `data/robotcar_frames_7k.txt` — список кадров.
- Таблицы и скрипты анализа — в `docs/results/`.

В конфигах и скриптах пути абсолютные (`/home/sitnikov_sv/...`), как они запускались на сервере.
В репозитории лежат конфиги актуальных экспериментов: блочная кросс-валидация RobotCar
(`cv_*`, `add_rc_*`, `f256_*`) и V4RL на 256/256 (`v256_*`); остальные восстанавливаются генераторами.
